# 名單總系統

給保險經紀人／業務員使用的名單管理工具：把**客戶名單**和**增員名單**放在同一份總名單裡，追蹤兩條流程、跟進提醒和每週活動量。

只有一個 `index.html` 檔，不需要安裝，也不需要帳號。手機、電腦的瀏覽器打開就能用。

## 功能

- **今天**：打開就看到今天要聯絡誰、接下來 7 天的安排，以及超過 30 天沒聯絡的人
- **一鍵跟進**：聯絡完按「完成」，一次記下聯絡方式、聊了什麼、推進階段、排好下一次
- **快速新增**：只填姓名就能存，其他資料收在「更多資料」可以之後再補；可連續新增多位
- **總名單**：每人一筆，可以同時是「客戶對象」和「增員對象」
  - 熟悉度（A/B/C）、影響力、關係、來源、介紹人、年齡層、職業、家庭、需求標籤
  - 電話一鍵撥打、LINE ID 一鍵複製
  - 個資同意勾選（提醒自己依《個人資料保護法》取得同意）
- **客戶流程**：未接觸 → 已約訪 → 已面談 → 需求分析 → 建議書 → 成交（另有「暫緩」）
- **增員流程**：未接觸 → 已接觸 → 事業說明 → 考照中 → 已報到 → 輔導期（另有「暫緩」）
  - 每個階段都會提示「下一步該做什麼」
- **數據**
  - 本週活動量對比目標（新增名單、約訪、面談、聯絡次數）
  - 目標反推：輸入每月成交件數，算出每月、每週需要的名單、約訪、面談數。某階段累積滿 5 人後，改用自己的實際轉換率
  - 客戶／增員漏斗與各階段轉換率
  - 名單來源分析：哪種來源成交率最高
- **備份**：JSON 備份與還原、匯出 CSV（Excel 可開），超過 14 天沒備份會提醒
- **使用說明**：右上角「?」隨時可以看名詞解釋；第一次打開有三步驟引導

## 使用方式

### 直接線上使用

打開這個 repo 的 GitHub Pages 網址即可（見 repo 右側 About 的連結）。

### 自己下載使用

下載 `index.html`，用瀏覽器打開就能用。

### 放到自己的 GitHub Pages

1. Fork 這個 repo
2. 到 **Settings → Pages**，Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`
3. 幾分鐘後就會有自己的網址

## 資料存在哪裡？

**所有名單只存在你自己裝置的瀏覽器裡（localStorage），不會上傳到任何伺服器**，其他人打開同一個網址也看不到你的資料。

所以要注意：

- 清除瀏覽器資料、使用無痕模式，資料會不見
- 手機和電腦的資料不會同步
- 請定期按「下載備份（JSON）」，換裝置時再用「從備份還原」

## 個資提醒

名單屬於個人資料。請不要記錄身分證字號、病歷等敏感資料，並在蒐集前取得對方同意。外幣保單的銷售另有適合度評估規定，相關紀錄請依所屬公司流程留存。

## 第一次打開

系統會放入 5 筆標示「範例」的示範名單，讓你先熟悉操作。熟悉後在頁面上方按「清除範例」即可刪除，不會影響你自己新增的資料。
